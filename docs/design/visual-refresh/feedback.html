Sample polished answer

0:14 / 0:36

“First, I would clarify whether the duplicates share a primary key or are distinct rows with identical data, and capture a reproducible request trace.

If storage has one row, I would check the read path: one-to-many joins multiplying rows, or offset pagination drifting as new rows arrive.

If storage has two rows, I would check the write path: client retries after timeouts, missing idempotency keys, and unique constraints, then add a regression test.”
